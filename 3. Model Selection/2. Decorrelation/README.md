# Decorrelation

This folder contains the second vein-CANN model-selection stage. It removes
candidate terms that produce nearly redundant strain-energy responses over the
biaxial stretch domain. The input is one cohort folder produced by the
[sensitivity-analysis stage](<../1.%20Sensitivity%20analysis/README.md>).

Sensitivity and decorrelation answer different questions:

- Sobol sensitivity ranks how strongly a term affects the sampled response.
- Decorrelation tests whether a lower-ranked term adds a numerically distinct
  response after higher-ranked terms have been considered.

This stage performs only pairwise numerical pruning. It intentionally does not
collapse multiple shapes from the same constitutive family; that structural
decision belongs to `3. Family collapse`.

## Method

The sensitivity stage provides a basis matrix `Psi` for both physiological and
extended biaxial stretch grids. The script computes the absolute Pearson
correlation between every pair of basis columns on each grid:

```text
rho_physio(i, j)  = abs(corr(Psi_physio[:, i],  Psi_physio[:, j]))
rho_extended(i,j) = abs(corr(Psi_extended[:, i], Psi_extended[:, j]))
```

By default, the pruning score is the maximum across grids:

```text
rho_combined(i, j) = max(rho_physio(i, j), rho_extended(i, j))
```

This is conservative: two terms are treated as redundant if they are highly
correlated on either grid. `--corr_combine mean` instead gives both grids equal
weight.

Candidates are visited from best to worst Sobol rank. A candidate is retained
only when its combined correlation with every previously retained term is less
than `--corr_threshold`. At the default threshold of `0.98`, a correlation of
exactly `0.98` is dropped.

Because the procedure is greedy, the ranking matters: the higher-ranked member
of a correlated pair is normally retained. The default ranking column is
`mean_ST_rank_primary`, which is generated by the sensitivity stage from its
selected primary regime.

Constant basis columns have undefined Pearson correlation. The implementation
assigns them zero correlation with other columns and retains a conventional
diagonal value of one. Such terms should also be examined for negligible Sobol
importance before model selection.

## Files

- `decorrelate_sobol_terms.py`: self-contained pairwise decorrelation script.
- `requirements.txt`: dependencies for this stage and its optional heatmap.

## Required input

Pass one sensitivity cohort directory, not the sensitivity results root. The
directory must contain:

```text
<sensitivity cohort>/
├── ranked_terms_sobol.csv
├── psi_matrix_physio.npz
└── psi_matrix_extended.npz
```

The two NPZ files must contain `psi` and `term_keys` arrays with identical,
unique term ordering. The script stops on ranking/matrix mismatches rather than
silently dropping or reordering terms.

## Environment

Python 3.10 or later is recommended. From this folder:

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

If the sensitivity-stage environment is already active, no separate
environment is needed; its dependencies are a superset of the core requirements
for this stage.

## Run

Run from the repository root. For a sensitivity cohort called `ALL_VEINS`:

```bash
python "3. Model Selection/2. Decorrelation/decorrelate_sobol_terms.py" \
  --sensitivity_dir "3. Model Selection/1. Sensitivity analysis/results/ALL_VEINS" \
  --out_dir "3. Model Selection/2. Decorrelation/results/ALL_VEINS" \
  --rank_col mean_ST_rank_primary \
  --corr_threshold 0.98 \
  --corr_combine max \
  --max_terms 25 \
  --make_plot
```

Run the script once for each anatomical cohort if sensitivity was performed
separately by cohort.

## Selection controls

### Threshold and grid combination

- `--corr_threshold`: candidates with combined `|rho| >= threshold` are
  removed. Lower values prune more aggressively.
- `--corr_combine max`: conservative default; redundancy on either grid is
  sufficient for removal.
- `--corr_combine mean`: balanced alternative; a large value on one grid can
  be moderated by a smaller value on the other.

The threshold is a model-selection assumption, not a universal constant. A
useful robustness check is to repeat the analysis at `0.95`, `0.98`, and `0.99`
and report which terms remain stable.

### Maximum size and category allocation

`--max_terms` limits the retained set before family collapse. Once the limit is
reached, remaining candidates are recorded in `pruning_log.csv` with reason
`max_terms_reached`.

An optional relative category allocation can be supplied:

```bash
--category_quota "iso=4,aniso=14,coupling=2"
```

The values are normalized and converted to integer limits that sum to
`--max_terms`; they do not need to sum to one. The legacy name `cross` is
accepted as an alias for `coupling`.

### Protected and blocked terms

Protection seeds a scientifically required term into the retained set before
the greedy walk. Repeat `--protect_term` for multiple terms:

```bash
--protect_term "invariant | I4el | Linear" \
--protect_term "strain | strain | E_θ·E_z"
```

`--protect_strain_linear` protects both `E_θ` and `E_z` linear strain terms.
Protected terms may correlate with one another; this is intentional and is
reported in the output. Protection should therefore be justified explicitly.

Blocking excludes a term regardless of its rank:

```bash
--block_term "invariant | I8fs | Exp quadratic"
--block_pattern "xlog"
--block_i8fs_nonlinear
```

Blocking takes precedence when a term is both blocked and protected. Quote all
term keys because they contain spaces and shell pipe characters.

## Outputs

| Output | Contents |
| --- | --- |
| `ranked_terms_sobol_pruned.csv` | Retained terms with original Sobol metadata and decorrelation diagnostics |
| `pruning_log.csv` | One auditable record for every blocked, correlated, quota-limited, or size-limited term |
| `correlation_matrix_physio.csv` | Absolute Pearson correlations on the physiological grid |
| `correlation_matrix_extended.csv` | Absolute Pearson correlations on the extended grid |
| `correlation_matrix_max.csv` | Pairwise maximum across grids |
| `correlation_matrix_mean.csv` | Pairwise mean across grids |
| `correlation_matrix_combined.csv` | Matrix actually used for pruning |
| `decollinearized_summary.txt` | Configuration, retained set, and correlated-pair audit |
| `collinearity_heatmap.png` | Optional visualization generated by `--make_plot` |

In `ranked_terms_sobol_pruned.csv`, `max_corr_with_kept` is the largest
correlation found when the term was admitted, and
`most_correlated_kept_term` identifies the associated retained term. In the
drop log, `dropped_for` identifies the retained term that displaced a
collinear candidate.

## Reproducibility and next stage

- Record the sensitivity result folder, rank column, threshold, grid-combination
  rule, maximum size, category allocation, and all protected or blocked terms.
- Keep the complete correlation matrices and pruning log; the retained CSV
  alone does not capture why alternatives were removed.
- Compare retained sets across plausible thresholds before fixing a final
  configuration.
- Pass `ranked_terms_sobol_pruned.csv` to `3. Family collapse`. Do not send the
  unpruned Sobol ranking directly to equation refitting unless decorrelation is
  intentionally being omitted and documented.
